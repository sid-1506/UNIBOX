# UNIBOX

UNIBOX is a unified messaging inbox designed to bring conversations from multiple messaging platforms—such as WhatsApp, Telegram, and Discord—into a single, consolidated interface.

The goal is to simplify message management and reduce app-switching fatigue by providing one central place to stay connected across different channels.

---

## Vision & Overview

Managing multiple messaging applications throughout the day can lead to fragmented communication and notification clutter. UNIBOX aims to bridge this gap by offering a cohesive workspace where users can monitor and participate in their conversations across platforms without jumping back and forth between standalone apps.

---

## Planned Features

As development progresses, UNIBOX is planned to include:

- **Unified Inbox:** A single view aggregating messages and threads across supported messaging platforms.
- **Unified Chat Interface:** A clean, responsive interface to view conversation histories and reply directly.
- **Smart / AI Capabilities (Future):** Exploring chat summaries, smart quick-replies, and message prioritization to keep focus on high-priority conversations.

> **Note:** These features represent the target roadmap and are not yet implemented.

## Getting Started

### Prerequisites

- Node.js (version 18 or higher recommended)
- npm, pnpm, or yarn

### Installation & Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sid-1506/UNIBOX.git
   cd UNIBOX
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
